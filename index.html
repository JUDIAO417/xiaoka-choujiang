保底中奖人数

保底机制：保底 N 人 = 本场从参与者中随机 N 人必中、其余人轮空（前 N 名同样可能轮空）。系统按「剩余轮空名额 / 剩余参与机会」动态调整轮空率，最终恰好 N 人中奖（需参与者 ≥ N 且库存 ≥ N×4）。抽空概率设为 100% 时必定全员抽空（优先于保底）。
